## 🚀 Featured Projects

### 🗺️ [AI-Assisted Global Mapping Engine](https://github.com/abdo0nasser/mapping-engine)
> *Python · FastAPI · SQLAlchemy Async · PostgreSQL · Pydantic v2 · RapidFuzz · Docker · React · TypeScript*

A real-time deduplication system that unifies hotel and city records from multiple global suppliers into a single canonical master catalog. Built under assessment conditions with a tight deadline.

- Multi-signal composite scoring for hotel matching: name similarity, geo proximity, star rating, hotel type, and city match — with configurable accuracy thresholds to minimize false positives
- Intelligent city matching using country-code gating + fuzzy name matching with accent/diacritic normalization
- Async data pipelines with SQLAlchemy async + asyncpg, connection pooling, and indexed PostgreSQL queries — designed to scale horizontally for millions of records
- Full-stack containerized deployment (Docker Compose) with a React dashboard featuring real-time mapping, geo-location map picker, and supplier metadata drill-down

### 📚 [Library & Lending API](https://github.com/abdo0nasser/Library-Application)
> *NestJS · PostgreSQL · Prisma · Redis · BullMQ · JWT · OAuth*

A production-grade RESTful API for managing book collections and lending workflows — designed to handle concurrency safely and scale gracefully.

- Cookie-based authentication + Social OAuth (Google/Facebook) integrations
- Atomic book borrowing/returning using Prisma transactions — safe under concurrent access
- Redis caching + rate limiting via `@nestjs/throttler` for performance and security
- Async email notification system using BullMQ + Redis — decoupled from the request lifecycle
- Structured application logging with Winston for full request lifecycle visibility
